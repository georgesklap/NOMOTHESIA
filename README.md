# ΥΕΦ – Νομοθεσία σε ισχύ

Εφαρμογή για το κινητό με την **τελική μορφή** (όπως ισχύει) της νομοθεσίας για:

- την **Υπηρεσία Εξωτερικής Φρούρησης** (ν. 2721/1999 άρθ. 48–51, π.δ. 215/2006, μισθολόγιο ν. 5246/2025, άδειες D/DE, οχήματα, στρατιωτική θητεία),
- τις **κοινές διατάξεις** (προσλήψεις, αποσπάσεις, μεταθέσεις, μετατάξεις, αργία 16ης Οκτωβρίου),
- το **σωφρονιστικό σύστημα** (άρθρα του Σωφρονιστικού Κώδικα που αλλάζουν, ΣΕΕΣΚ, ΓΓΑΠ, Κορυδαλλός κ.ά.).

Η αρχική οθόνη είναι **θεματική** (Υπηρεσιακά, Μισθολόγιο, Προσλήψεις–μεταθέσεις, Καθήκοντα, Σωφρονιστική νομοθεσία, Νέοι νόμοι). Υπάρχει και η ενότητα «Όλοι οι νόμοι» με την αρχική δομή.

Κάθε παράγραφος έχει από κάτω ένα μικρό σχόλιο: *Ισχύει / Τροποποιήθηκε / Νέο / Καταργήθηκε / Προσοχή* και από ποιο άρθρο.
Έχει αναζήτηση με λέξεις (χωρίς τόνους), λειτουργεί **χωρίς ίντερνετ** και έχει ενότητα με τα **PDF** για κατέβασμα.

---

## Ανέβασμα στο GitHub (μία φορά, ~5 λεπτά)

> Καλύτερα από υπολογιστή. Από κινητό το GitHub δεν ανεβάζει εύκολα φακέλους.

1. Μπες στο **github.com** και φτιάξε δωρεάν λογαριασμό (αν δεν έχεις).
2. Πάνω δεξιά **+** → **New repository**.
   - Όνομα: π.χ. `yef-nomothesia`
   - Επίλεξε **Public** (η δωρεάν σελίδα GitHub Pages θέλει δημόσιο αποθετήριο).
   - Πάτα **Create repository**.
3. Στη σελίδα που ανοίγει πάτα το link **uploading an existing file**.
4. Αποσυμπίεσε το zip στον υπολογιστή. Μπες **μέσα** στον φάκελο και σύρε **όλα τα περιεχόμενα**
   (`index.html`, `data.js`, `sw.js`, `manifest.json`, `README.md`, `.nojekyll`, και τους φακέλους `icons` και `pdf`)
   μέσα στο παράθυρο του GitHub. Περίμενε να ανέβουν όλα.
   - Αν δεν φαίνεται το `.nojekyll` (κρυφό αρχείο), δεν πειράζει.
5. Κάτω πάτα **Commit changes**.
6. Πήγαινε **Settings** → αριστερά **Pages**.
   - *Source*: **Deploy from a branch**
   - *Branch*: **main** και φάκελος **/ (root)** → **Save**.
7. Σε 1–2 λεπτά η εφαρμογή είναι στη διεύθυνση:
   `https://ΤΟ-ΟΝΟΜΑ-ΣΟΥ.github.io/yef-nomothesia/`

## Εγκατάσταση στο κινητό

- **Android (Chrome):** άνοιξε τη διεύθυνση → μενού **⋮** → **Εγκατάσταση εφαρμογής** (ή «Προσθήκη στην αρχική οθόνη»).
- **iPhone (Safari):** άνοιξε τη διεύθυνση → κουμπί **Κοινοποίηση** → **Προσθήκη στην οθόνη Αφετηρίας**.

Μετά την πρώτη φόρτωση δουλεύει και offline. Κάθε PDF μένει αποθηκευμένο αφού το ανοίξεις μία φορά.

## Ενημέρωση στο μέλλον

Αν σου δοθεί νέο `data.js` (π.χ. όταν δημοσιευτεί το ΦΕΚ του νόμου):
1. Στο GitHub ανέβασε το νέο `data.js` (Add file → Upload files) – αντικαθιστά το παλιό.
2. Άνοιξε το `sw.js` (μολύβι ✏️) και ανέβασε κατά 1 τον αριθμό στο `VERSION` (π.χ. `yef-v2` → `yef-v3`). Commit.
3. Στο κινητό κλείσε και ξανάνοιξε την εφαρμογή δύο φορές.

## Περιεχόμενο φακέλων

| Αρχείο | Τι είναι |
|---|---|
| `index.html` | Η εφαρμογή |
| `data.js` | Όλα τα νομικά κείμενα (ενοποιημένα) – δεν αλλάζει |
| `topics.js` | Θεματικό ευρετήριο: κατηγορίες → θέματα → παραπομπές στα άρθρα του `data.js` (δεν περιέχει νομικό κείμενο) |
| `sw.js` | Λειτουργία χωρίς ίντερνετ |
| `manifest.json`, `icons/` | Εγκατάσταση ως εφαρμογή |
| `pdf/` | Τα επίσημα κείμενα (ΦΕΚ, νομοσχέδιο) |

## Σημαντικό

Η εφαρμογή βασίζεται στο κείμενο του νομοσχεδίου (63 άρθρα) και στα ΦΕΚ του φακέλου `pdf`.
Αν το τελικό ΦΕΚ διαφέρει, υπερισχύει το ΦΕΚ. Ο πλήρης κωδικοποιημένος Σωφρονιστικός Κώδικας δεν περιλαμβάνεται – μόνο τα άρθρα του που αλλάζουν.
Δεν αποτελεί νομική συμβουλή.
